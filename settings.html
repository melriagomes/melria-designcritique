Getting a Figma personal access token

  1. Log into Figma in your browser, then click your account icon (top-left) and open Settings.
  2. Go to the Security tab and scroll to Personal access tokens.
  3. Click Generate new token, give it a name (e.g. "Design Critique Agent"), and set an expiry.
  4. Under scopes, select at minimum File content — Read only. This is what lets the token fetch a file's design so it can be rendered as an image for critique.
  5. Optional: Current user — Read only is not required for critiques; it's only used by this app's diagnostics to confirm which account a token belongs to.
  6. Click Generate token and copy it immediately — Figma only shows it once. Paste it into the field on this page and click Save.

Treat this token like a password — anyone with it can read any Figma file it has access to.
