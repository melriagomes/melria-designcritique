Getting a Figma personal access token

  1. Log into Figma in your browser, then click your account icon (top-left) and open Settings.
  2. Go to the Security tab and scroll to Personal access tokens.
  3. Click Generate new token, give it a name (e.g. "Design Critique Agent"), and set an expiry.
  4. Under scopes, turn on every permission that lets the token read files — at minimum File content: Read, and also File metadata: Read, Library content: Read, and Library assets: Read if Figma shows them. These let the token fetch the file's design so it can be rendered as an image.
  5. Also turn on every Dev permission in the list (e.g. Dev resources: Read, Code Connect: Read) — Figma can require these to fully retrieve a file's contents through the API, even for a plain design file.
  6. Optional: Current user — Read only is not required for critiques; it's only used by this app's diagnostics to confirm which account a token belongs to.
  7. Click Generate token and copy it immediately — Figma only shows it once. Add it below as a new key (name it something like "Figma") and mark it active.

This is only for Figma links. For any other website, add its API key the same way — it'll be sent as a standard bearer token when you paste that site's URL.

Treat every key here like a password — anyone with it can access whatever it's scoped to.
